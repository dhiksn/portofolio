AutoDeploy AI

CLI tool Python yang mengotomatisasi seluruh proses deploy ke GitHub — dari git init, generate commit message pakai AI, hingga push — semuanya dalam satu command autodeploy dari terminal mana pun.

Install & Cara Pakai

# Install via pip
pip install autodeploy-ai --upgrade

# Project baru (belum ada .git)
autodeploy https://github.com/username/repo

# Project yang sudah punya remote
autodeploy

# Ubah konfigurasi AI provider
autodeploy --setup

AI Provider yang Didukung

⚡
Groq
Online, gratis, dan sangat cepat. Menggunakan model llama-3.1-8b-instant. Butuh API key dari console.groq.com.
🖥️
Ollama
Jalankan AI secara lokal di komputer sendiri. Gratis, tidak butuh API key, dan data tidak keluar dari mesin. Butuh Ollama running.
🤖
OpenAI
Menggunakan GPT-4o-mini dari OpenAI. Berkualitas tinggi namun berbayar. Cocok untuk tim yang sudah punya API key OpenAI.

Fitur Unggulan

🔧
Auto Git Init
Deteksi otomatis apakah project sudah punya .git — kalau belum, langsung init dan set remote.
✨
AI Commit Message
Generate commit message bermakna secara otomatis berdasarkan perubahan file yang ada.
✅
Validasi Repo
Cek apakah repo GitHub benar-benar ada sebelum push untuk mencegah error.
🎯
Setup Wizard
Guided setup interaktif saat pertama kali dijalankan — pilih provider AI dan masukkan API key.
🌐
Global CLI
Setelah install, command autodeploy tersedia dari folder mana pun.
🗑️
Clean Uninstall
Hapus package dan semua konfigurasi sekaligus dengan --uninstall.
